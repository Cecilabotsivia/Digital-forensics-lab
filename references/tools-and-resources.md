# Digital Forensics Lab – Tools and Resources

This document lists the official tools, platforms and learning resources used or referenced during this educational digital forensics project.

## 1. NIST CFReDS

**Full name:** Computer Forensic Reference Data Sets

**Purpose:** Provides publicly available forensic images and reference datasets for research, testing and digital forensic training.

Website: https://cfreds.nist.gov/

Dataset used: `2020JimmyWilson.E01`

## 2. Autopsy

**Purpose:** Digital forensic investigation platform used to examine forensic disk images, file systems and digital artefacts.

Official website: https://www.autopsy.com/

## 3. The Sleuth Kit

**Purpose:** Open-source digital forensic toolkit for analysing disk images and file-system artefacts.

Official website: https://www.sleuthkit.org/

## 4. Microsoft PowerShell

**Purpose:** Used to calculate SHA-256 hashes for evidence integrity verification.

Official documentation: https://learn.microsoft.com/en-us/powershell/

## 5. GitHub

**Purpose:** Hosts the public project documentation, methodology, findings and selected examination screenshots.

Official website: https://github.com/

## 6. Project Scope

These resources support an educational digital forensics workflow involving:

- Evidence identification and preservation.
- Cryptographic hash calculation.
- Forensic disk image examination.
- File-system analysis.
- Windows artefact examination.
- Technical documentation and reporting.

## Disclaimer

This project is conducted for educational and professional development purposes. The public training dataset is used for forensic learning and does not represent an investigation of a real-world criminal allegation.
