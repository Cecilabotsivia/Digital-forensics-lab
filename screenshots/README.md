This directory contains selected screenshots documenting the practical examination activities performed during this educational digital forensics project.

1. Autopsy case creation.
2. Forensic image successfully added as a data source.
3. Evidence hash verification.
4. Partition identification.

## Screenshot Handling

- Screenshots are selected for educational and portfolio documentation.
- Original forensic evidence files are not included.
- Sensitive personal information and unrelated private information must be excluded.
- Screenshots must accurately represent activities performed during the examination.
